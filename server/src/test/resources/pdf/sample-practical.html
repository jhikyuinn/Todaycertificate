문제 1

예시-1

다음 Python 코드를 실행하면 출력되는 값을 적으시오.

def total(items):
    result = 0
    for x in items:
        if x % 2 == 0:
            result += x
    return result
print(total([1, 2, 3, 4]))

정답 및 해설

6

[해설]

짝수인 2와 4만 더하므로 6이다.
