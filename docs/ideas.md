# 나중에 판단할 아이디어

완료 기준 밖의 개선 제안. 지금은 진행하지 않는다.

- 앱 스토어 배포 (EAS Build). 코드는 Expo라 같은 코드로 가능
- 주관식·실기 문제 (단답형 채점 규칙 필요)
- 그림이 있는 문제 (이미지 업로드, 저장소)
- 문제별 댓글 (운영자 삭제·신고 처리 필요)
- 공공데이터포털 국가자격 종목 API로 자격증 목록 가져오기
- UI 개편
- 시험 점수 이력
- Flyway 이후 스키마 변경 이력 관리 고도화
- API별 개선·확장 후보는 `docs/API.md`의 각 절 "개선·확장 후보"에 모아 두었다
- 실기 CSV에서 글자 답을 `정답번호` 칸에 쓰는 것이 헷갈린다 → 헤더 별칭 `정답` 허용
- PDF 가져오기: 페이지 꼬리말(쪽 번호, 사이트 안내 문구)이 그 페이지 마지막 문제의 보기 4번 뒤에 붙고, 마지막 쪽 정답표가 마지막 문제에 붙는다 → 파서에서 쪽 번호 줄·반복되는 머리말/꼬리말 줄 제거. 지금은 미리보기 표에서 고친다
- PDF 가져오기: 보기 앞뒤 공백이 남는 경우가 있다 → 파서에서 strip
- 실기 PDF: 워터마크 줄(사이트 이름)이 해설에 섞일 수 있다 → 글자 색·크기로 거르기. 지금은 미리보기 표에서 지운다
- 실기 PDF: 단어 중간에서 줄이 넘어간 곳에 공백이 들어간다("리 스트") → 줄 끝 글자 위치로 판단
- 실기 PDF: 영문이 대부분인 글 2줄(보기 목록 등)이 코드 블록으로 잡힐 수 있다 → PDF 글꼴(고정폭)로 코드 판단
