# 나중에 판단할 아이디어

완료 기준 밖의 개선 제안. 지금은 진행하지 않는다.

- 앱 스토어 배포 (EAS Build). 코드는 Expo라 같은 코드로 가능
- 주관식·실기 문제 (단답형 채점 규칙 필요)
- 그림이 있는 문제 (이미지 업로드, 저장소)
- 문제별 댓글 (운영자 삭제·신고 처리 필요)
- 공공데이터포털 국가자격 종목 API로 자격증 목록 가져오기
- UI 개편
- 시험 점수 이력
- Flyway 이후 스키마 변경 이력 관리 고도화
- API별 개선·확장 후보는 `docs/API.md`의 각 절 "개선·확장 후보"에 모아 두었다
- 시험 결과 화면의 과락선이 40점으로 고정되어 있다 (`attempts/[attemptId].tsx`의 `FAIL_SCORE`). 실기처럼 `failScore`가 0인 자격증은 선과 안내 문구가 맞지 않는다 → 응답에 자격증 기준을 담아 그리기
- 주관식 문제에서도 "1~4 보기 선택" 단축키 안내가 보인다 → 문제 유형에 따라 숨기기
- 실기 CSV에서 글자 답을 `정답번호` 칸에 쓰는 것이 헷갈린다 → 헤더 별칭 `정답` 허용
