## 필수
- [ ] 비밀값이 현재 코드에 없다 (과거 기록의 DB 비밀번호는 PostgreSQL 전환으로 폐기)
- [ ] 서버가 Spring Boot + JPA + PostgreSQL로 동작한다
- [ ] 회원가입·로그인을 서버에서 처리한다 (BCrypt, JWT, USER/ADMIN 권한)
- [ ] 운영자가 자격증(설명, 과목, 일정, 시험 기준)을 관리하고 회차별 기출을 CSV로 올린다
- [ ] 사용자가 자격증을 골라 공부 모드로 기출을 푼다
- [ ] 시험 모드: 제한시간, 과목별 점수, 과락, 합격 여부
- [ ] 오답노트와 별표 문제
- [ ] 채점·과락·CSV 검증 테스트가 통과한다
- [ ] 서버(Render), DB(Neon), 웹(Vercel)이 배포되어 데모 계정으로 접근된다
- [ ] README만 보고 로컬에서 실행되고, 구조와 기술 선택 이유가 있다. 운영자 화면 데모 영상이 있다
